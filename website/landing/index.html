Questions

Is this just a clipboard manager?

No. Clipboard history is one feature. PasteDeck also keeps snippets, candidate sessions, blueprints for capturing and filling forms, files and reminders, organised into desks.

Where is my data stored?

On your device, in Chrome's local extension storage. Nothing is uploaded. Cloud sync for teams will be optional and off by default.

Does it work on WhatsApp Web and Gmail?

Yes. Snippets insert into the message box you are typing in. If a site blocks direct insertion, PasteDeck copies the text so you can paste it yourself.

What is a blueprint?

A blueprint is a memory of where things are on a website. You click a field once and name it. PasteDeck stores the location, so on the next page of that site it can read the same fields, or fill the same form.

Do blueprints use AI?

No. They use the page structure you pointed at. That keeps them fast, predictable and private. If a site changes its layout, teach it again.

What happens when a session expires?

You choose 15 minutes, 30 minutes, 1 hour or end of day. When time is up, the session and its files are deleted.

Can my team share snippets and files?

Owners and admins can set company details and share snippets, desks, images and blueprints with staff. Team sync arrives with the cloud release.

Install PasteDeck

The Chrome Web Store listing is on its way. Until then, load the extension yourself in a minute.

Log in
  1. Download the PasteDeck folder and unzip it.
  2. Open chrome://extensions and switch on Developer mode.
  3. Click Load unpacked and choose the extension folder.
  4. Press Ctrl+Shift+Space on any page.
